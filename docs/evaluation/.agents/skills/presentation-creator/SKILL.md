# Ironhack Presentation Creator

Analyze the current VS Code workspace and create a professional PowerPoint presentation.

## Instructions

1. Read the project README, source code, AGENTS.md, and documentation.
2. Find and follow the Ironhack presentation template.
3. Cover:
   - Project overview and motivation
   - Quality, Time, Cost (Q/T/C)
   - Stakeholders, top risk, WBS and Kanban board
   - Knowledge base architecture
   - RAG decision and justification
   - Pipeline demonstration
   - Project uniqueness
   - Technical implementation and AGENTS.md
   - Challenges and solutions
   - Kanban Day 1 versus Day 2
4. Use only verified information from the project.
5. Identify missing information rather than inventing it.
6. Generate an editable PowerPoint presentation.
7. Prepare speaker notes for three team members.

Save outputs in presentation_output/.
